How a sale gets credited
  1. Someone types the code in onboarding (“How did you find Quran Scroll?”) or Menu → Creator code, or taps the creator’s link with the app installed. First code on a phone wins.
  2. The app tags them in Superwall (creator_code). Every App Store purchase, renewal and refund comes back through the Superwall webhook with that tag.
  3. Pay monthly: switch to Last month, pay each creator what they’re owed (Apple pays you about 30–45 days after the month), then press Record payout.
